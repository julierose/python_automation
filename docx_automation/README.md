# Word Document Automation Demo

A demonstration of automating branded Word document creation using [python-docx](https://python-docx.readthedocs.io/), pandas, and seaborn/matplotlib. This script loads an existing branded template (with a header image already built in), adds styled headings and body text, embeds a chart built from sample data, and demonstrates two different approaches to text formatting — a pattern well-suited for recurring reports, client memos, or any document that needs to be regenerated on a schedule.

## What it does

1. Builds a sample dataset with pandas and creates a boxplot with seaborn.
2. Saves the chart to a temporary file (never committed to the repo).
3. Opens `Sample_Document_Template.docx` — a pre-branded Word template with a header image already in place.
4. Sets document-level styles (Heading 1, Heading 2, Normal) for consistent formatting throughout.
5. Adds a heading, a "last refreshed" date, and body text using named styles (**Approach 1**).
6. Embeds the chart image below that text.
7. Inserts a page break, then adds a manually-formatted callout paragraph using `.add_run()` (**Approach 2**) — demonstrating one-off formatting outside the style system, and proving the header repeats correctly across pages.
8. Saves the result as `Sample_Document_Updated.docx`.

## Requirements

- Python 3.11 or higher
- Packages listed in `requirements.txt`

Install dependencies:

```
pip install -r requirements.txt
```

> **Note:** this project is built and tested on pandas 3.0.5, a recent major release (January 2026) that changed some default behaviors (e.g. copy-on-write is now on by default). If you already have an older version of pandas installed in a shared environment, running `pip install -r requirements.txt` will upgrade it — which could affect other projects relying on pre-3.0 behavior. Consider using a virtual environment to keep this isolated.

> **Note on package naming:** the import statement in this script is `from docx import Document`, but the package to install is `python-docx`, **not** `docx`. There's an old, unrelated, unmaintained package on PyPI literally called `docx` that shares the same import name — installing it instead will cause errors. Always install via `pip install python-docx`.

## Usage

From within this folder:

```
python generate_document.py
```

(On Mac/Linux, you may need `python3` instead of `python`, depending on your setup.)

This will regenerate `Sample_Document_Updated.docx` in the same folder, using the current date for the "last refreshed" text.

## Template requirements

This script is written against `Sample_Document_Template.docx`, which has the branded header image built in directly (added manually in Word, not generated by the script). If you swap in your own template:

- Build your header image/branding directly into the template's header in Word, rather than trying to insert it via code — python-docx has limited, finicky control over header image positioning, whereas Word's own layout engine handles it reliably.
- Make sure the template's body doesn't start with a stray empty paragraph — the script checks for and removes one automatically if present, but it's worth confirming in Word directly.

## Customizing for your own use

This script is meant as a starting point. Common things to adjust:

- **Data**: replace the `dummy_data` dictionary with your own data source (CSV, Excel, database query, API call, etc.)
- **Chart type/styling**: swap the seaborn boxplot for any chart type, or adjust colors/fonts to match your brand
- **Heading/body styles**: adjust the `heading1_style`, `heading2_style`, and `normal_style` blocks near the top of the script
- **Chart size**: adjust the `width` passed to `doc.add_picture(...)`
- **Template and header**: swap in your own branded `.docx` file with your own header image built in (see template requirements above)
